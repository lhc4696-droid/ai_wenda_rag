# 前端视觉优化与验收

日期：2026-10-19。

## 设计与实现

本次优化现有登录、普通聊天和编程工作台，统一为浅色工作区、石墨色文字和蓝紫色强调。保留当前工作区已有的账号、聊天、流式输出、附件、项目及目录授权逻辑。

- 登录：深石墨色品牌展示区，立体方块与轨道、悬浮对话和代码卡片；登录、注册、找回密码共用一致的表单控件。小屏优先展示表单。
- 普通聊天：居中欢迎区、分层提示卡片、清晰的新建对话与编程入口、统一的输入框与消息配色。低高度窗口允许欢迎内容自然滚动，避免与输入框重叠。
- 编程工作台：浅色三栏、清晰的面板分隔、可读的按钮与连接提示。窄屏目录和过程抽屉脱离桌面网格轨道定位，解决面板宽度缩成 1px 的问题。
- 可访问性：次级文字 `#626b7e` 在白色、浅灰及浅紫选中背景上的对比度分别约为 5.35:1、5.04:1、4.65:1；保留键盘焦点样式与减少动态效果偏好。低高度侧栏使用紧凑布局，保留历史记录滚动空间。

使用 3Dviz Pro Max 的设计指导，实际检索并参考了 `knowledge.style-glass-translucent` 与 `knowledge.style-geometric-abstract`。定制的 `IdeaSculpture.vue` 以 CSS 3D 实现立体装饰，使用 scoped 样式、`aria-hidden` 和 `pointer-events: none`，只用于登录展示区及两处欢迎页。没有增加运行时依赖，也没有持续渲染循环；该装饰是品牌视觉表达。

## 修改入口

- `frontend/src/components/IdeaSculpture.vue`：共用立体装饰。
- `AuthView.vue`、`ChatWorkspace.vue`、`LocalCodingWorkspace.vue`：接入装饰与展示排版。
- `styles.css`、`auth.css`、`local-coding.css`、`coding.css`、`history.css`：配色、控件、响应式与布局修正。
- `frontend/tests/e2e/workspace-layout.spec.js`：低高度欢迎页不重叠，以及窄屏抽屉可完整显示并从内部关闭的回归用例。
