# 项目目录与多对话

更新：2026-10-13。对应《2026-10-10待做》第一项；代码已实现，仅作静态检查，真实迁移和功能验收由你执行。

## 使用方式

1. 编程工作台左侧点「添加项目」，填写可选的项目名称，确认知言的项目授权说明，再由浏览器选择本地目录。
2. 在中间输入需求并发送，第一条需求会在该项目下建立一个对话。
3. 点「新建项目对话」开始独立聊天；目录记录和浏览器权限有效时，直接使用同一个根目录，不再选文件夹。
4. 左侧「项目对话」仅显示当前项目的记录，点击可继续之前的聊天。
5. 使用「当前项目」下拉框切换项目，目录和对话列表随之切换。列表只显示项目名称，不展示内部 ID 或短编号。

### 项目命名

- 创建时可填写名称，最多 120 个字符，前后空格会去除；不填写时按当前账号自动生成「项目 1」「项目 2」等。
- 默认编号由后端事务分配并持久化，不按页面列表长度计算。刷新、换浏览器、删除或重命名项目后不倒退，不回收已经分配的默认编号；如果下一个名称已被手动占用，会跳过。
- 自定义名称不消耗默认编号。不同账号各自编号；允许自定义同名项目，但列表不展示内部编号，建议使用不同名称便于辨认。系统仍使用完整 ID 区分项目。
- 选中项目后点击「重命名」可修改显示名称；留空保存会分配下一个默认编号。
- 名称和真实文件夹名是两个字段。重命名不改动磁盘目录，不改变句柄、对话归属或文件读写权限；左侧仍展示真实文件夹名供核对。
- 已有项目升级后保留原文件夹名作为显示名称，不擅自更名。可以通过「重命名」调整。

对话共享实际磁盘文件，但不自动共享聊天上下文。B 对话能读取 A 对话已经修改的文件，不意味着 B 自动知道 A 聊过什么。每次执行会重新扫描路径，需要内容时再调用读取工具，不复用旧文件基线。

只连接、切换项目、打开历史不会调用模型或重放旧工具。新建空白对话暂不存入数据库，发送首条需求时才创建。

## 授权、断开与删除

- 知言授权的范围是此项目下面的所有对话；浏览器目录读写许可仍需用户亲自确认，不能跳过。
- 主动断开会禁用整个项目的目录连接，保留原句柄以核对下次重连是否为同一目录；其他对话同样不能继续操作。
- 停止只结束当前执行，不断开项目目录，不撤销已经保存的文件修改。
- 删除一个对话只删除该对话和服务端轮次记录，不清除项目句柄，不影响其他对话。
- 删除项目需要二次确认，会级联删除项目下全部对话、轮次记录，并清除本浏览器的对应句柄；不会删除磁盘项目文件，也不会清除本地恢复备份。记录删除不可在应用内撤销，升级前的数据库备份可以用于恢复旧记录。
- 退出账号清除该账号在此浏览器记住的目录句柄，不删除数据库历史。
- 浏览器权限有效且应用连接启用时，追加需求直接继续。权限失效但原目录句柄仍在时，点击「恢复访问」，仅对已保存的目录调用浏览器授权，不打开目录选择器；准备弹窗和打开历史本身不会申请权限。
- 主动断开但记录仍在时，也可明确点击「恢复访问」重新启用项目连接。拒绝或取消不会启动任务，不会自动改成选目录。若浏览器已禁止权限，需先检查站点权限设置。
- 清理站点存储、换浏览器或退出账号后，没有保存的句柄，需要重新选择原目录。句柄不可用时可手动点击「重新选择原目录」；有旧句柄时仍用 `isSameEntry` 核对目录，不能仅凭同名换绑。无法核对旧句柄时不会静默放宽校验。
- 授权弹窗打开后，如果另一个标签页断开连接或退出账号，旧授权确认不能恢复已撤销的连接；需要关闭提示、重新发起连接。目录绑定带独立修订号，恢复时检查账号、项目、原句柄和修订号。
- 保持原来的同账号单活跃任务限制，以及同浏览器站点的全局文件操作锁；不能同时启动多个对话写文件。

## 数据和接口

### 编程工作台的账号与模型设置

右上角头像/用户名支持点击、鼠标悬停及键盘操作，菜单提供「账号设置」「模型设置」「退出登录」。点击模型设置会直接打开共享账号弹窗的模型页，可修改 API Key、Base URL、编程模型或切回默认模型，无需返回基础聊天。保存后两边模型信息同步刷新，新配置用于后续任务，不重置项目、对话、草稿或目录连接。

当前操作或编程任务未结束时，设置入口显示禁用原因；请先等待或停止任务再修改。后端原有执行中保护仍会拦截跨标签页的配置冲突。执行中退出登录会先询问确认，确认后停止本页文件操作再退出；已写入的文件不会自动撤销。修改用户名、密码沿用已有账号接口及登录保持规则。

验收时可在工作台保存新编程模型，关闭弹窗后核对顶部模型名、未发送草稿及项目目录仍在；切回基础聊天核对账号和模型同步。模拟浏览器回归源码为 `frontend/tests/e2e/coding-account.spec.js`，本次未执行。

关系：`local_coding_projects → local_coding_conversations → local_coding_tasks`。

- `local_coding_projects`：用户、项目编号、客户端幂等编号、显示名称 `name`、创建时的原始名称 `name_request`（用于重试校验）、目录显示名、时间。服务器不保存浏览器句柄或本地绝对路径。
- `local_coding_project_numbers`：每个账号最后分配的默认名称编号；删除项目不会清除此计数。
- `local_coding_conversations.project_id`：指向所属项目；API 验证同账号归属与目录名，数据库触发器也限制跨账号或更换项目。
- `local_coding_tasks`：原有每轮执行状态不变。模型历史仍只取当前用户、当前对话的近期记录。
- 浏览器 IndexedDB 逻辑键改为「用户 ID + 项目 ID」。为保留已有句柄，物理 keyPath 仍沿用旧名 `conversationId`；它不是新对话的 ID，代码中有兼容说明。

新增接口：

| 接口 | 用途 |
| --- | --- |
| `POST /api/coding/local/projects` | 创建项目，提交 `client_project_id`、`directory_name`，可选 `name` |
| `GET /api/coding/local/projects` | 当前账号的项目列表 |
| `PATCH /api/coding/local/projects/{id}` | 提交 `name` 重命名，留空分配下一个默认名称 |
| `DELETE /api/coding/local/projects/{id}` | 删除项目和所属对话；活跃执行时拒绝 |
| `POST /api/coding/local/conversations` | 新增 `project_id`，在该项目下创建对话 |

对话响应新增 `project_id`。兼容旧客户端未传 `project_id` 的创建请求时，后端会单独建立项目，不按文件夹名称归并。每账号最多 100 个项目、100 个对话和 1000 轮记录，每对话最多 200 轮；本次未提高额度。

## 升级步骤

数据库当前版本为 11：`010_local_coding_projects.sql` 提供多对话项目，`011_local_project_names.sql` 添加项目名称与账号编号计数。尚未升级的旧库会依次迁移。不要手动删表、删库或直接把最新 schema.sql 导入旧库。

1. 等待或停止所有编程执行，然后停止后端。
2. 在项目根目录执行备份迁移命令：

   ```powershell
   .\venv\Scripts\python.exe backend\migrate_db.py --backup
   ```

3. 按原方式启动后端；开发前端刷新页面即可，生产环境需重新构建并部署前端。关闭旧版本页面，避免继续使用旧的按对话管理句柄逻辑。
4. 打开编程工作台，检查旧对话是否在对应项目中。

每个旧会话各迁为一个项目，项目 ID 等于旧会话 ID，所以原来保存的浏览器句柄仍可查到；已禁用的授权不会被重新启用。即使旧会话目录显示名相同，也不自动合并，因为名字不能证明两个目录是同一个真实文件夹。原任务、回答和轮序保持不变。

本次没有替你运行迁移，没有读写真实 `.env`、数据库或用户项目文件，也没有操作 Git。

## 建议验收

1. 项目 A 选一次目录，在 A 下先后新建两个对话：第二个发送时不再出现目录选择框，两段聊天各自独立。
2. 第一个对话创建文件，第二个对话要求读取这个文件：应看到最新磁盘内容，但不会出现第一个对话的历史消息。
3. 新建项目 B，切换 A/B：目录名、对话列表、历史过程和修改记录不得串用。
4. 删除 A 的一个对话，另一个仍可继续；删除 A 全部对话后项目仍存在，仍可新建对话复用目录。
5. 主动断开 A，在 A 的其他对话发消息，应提示重连；选择另一个同名目录应被原句柄校验拒绝。
6. 刷新、打开历史不应执行任何工具；退出再登录后需要重新连接。
7. 项目执行中删除应被拒绝；确认删除项目后本地文件及恢复记录仍在，数据库对话记录消失。
8. 备份后升级已有版本 9 数据库，核对旧记录和句柄仍可用；不同账号看不到彼此项目。
9. 连续创建两个不填写名称的项目，应依次编号；删除后再创建默认编号应继续增加。创建自定义名称并重命名，真实文件夹名、授权和已有对话不得变化。
10. 保留站点存储，仅让目录权限需要再次询问：旧对话追加需求应出现「恢复访问」，点击后只请求原目录权限；允许后继续本次需求，不再选目录。拒绝后不执行任务，不弹目录选择器。
11. 打开恢复授权弹窗后，在另一个标签页断开该项目，再确认旧弹窗：不得重新启用连接。退出账号后再登录，因目录记录已清除，应要求重新选目录。
