# 知言 AI 前端界面优化

日期：2026-09-16。范围：仅前端布局、配色和交互；不修改后端接口、数据库或真实配置。

## 本轮变化

- 账号入口从左下角移到右上角，头像、用户名和下拉箭头组成一个按钮。长用户名省略显示，账号资料里可查看完整名称。
- 电脑悬停展开，移动到列表时保留菜单；点击可固定展开，再次点击或点外部关闭。手机直接点击，不依赖悬停。
- 2026-09-17 更新：菜单合并为账号设置、退出登录。模型回答期间账号设置不可用，退出登录保留。
- 支持 Tab、Enter、方向键、Home/End 和 Esc；打开设置后使用对话框焦点约束，关闭后回到账号入口。
- 设置弹窗拆为账号资料和安全设置两个选项卡；从统一的账号设置入口进入，修改密码在安全设置中操作。切换选项卡清除未提交密码；改名不再需要当前密码，改密规则不变。
- 白色主界面、浅灰侧边栏、深色正文，蓝色用于主要操作和选中状态。登录、注册、找回密码、错误提示、设置弹窗及网站图标一并统一；不新增深色模式切换。
- 欢迎语改为“今天想聊些什么？”，保留三个提问建议；用户消息浅灰底，AI 回答白底，统一正文宽度、行距与代码块样式。
- 侧边栏不再重复显示账号操作，仅保留品牌、新建对话、当前对话和页面记录说明；不增加虚假的历史记录入口。

## 查看与手动验收

若已运行 pnpm dev，可直接查看开发页面。2026-09-17 新增历史功能后，对话会保存到当前账号，刷新可恢复；旧版本已经丢失的消息无法补回。当前侧栏已扩展为真实历史列表，详见 [聊天历史实现与验收](聊天历史实现与验收.md)。本轮没有重新构建 dist，pnpm preview 或旧部署产物不会自动获得修改。

按用户要求，不运行功能测试、浏览器联调或构建，只做语法与静态编译检查。回归用例已随入口变更同步更新，但不代表通过。

建议人工检查：

1. 电脑把鼠标移到右上角用户名，再移入菜单；移动到外部后应收起。点击固定展开后，点外部或按 Esc 关闭。
2. 手机宽度下直接点击右上角头像和用户名，确认无需展开左侧导航，菜单不超出屏幕。
3. 点击账号设置，确认邮箱、当日用量和无密码确认的用户名修改表单；再点击安全设置，确认修改密码表单仍需当前密码。
4. 在两个选项卡之间切换，确认未提交的密码清空；关闭弹窗后键盘焦点回到账号入口。
5. 改名后右上角同步更新且当前聊天保留；主动改密后显示成功提示、清空密码输入框，当前浏览器保持登录并保留聊天和草稿，其他旧登录失效。邮箱找回密码仍返回登录页。
6. 检查登录、注册和找回密码的配色；查看长回复、代码块、小屏布局和输入框蓝色焦点状态。
