# 知言 AI

Vue 3 + FastAPI + SQLite 的个人 AI 项目，默认由后端调用阿里云百炼 / 通义千问，也支持每个账号使用自己的 OpenAI 兼容模型服务。当前版本 0.10.0，支持邮箱验证码注册、登录、密码找回、个人账号与模型设置、持久化聊天历史、文档/图片问答、按需 RAG，以及用户授权的本地文件夹编程。

## 目录

- frontend：Vue 页面和浏览器 API 调用。
- backend：FastAPI 接口、认证、数据库、模型与邮件服务。
- docs：需求、配置说明和验收清单。
- venv：本机 Python 虚拟环境，不存放业务源码，不提交版本控制。

## 运行

第一次在新电脑搭建环境，请从 [新电脑环境搭建与项目迁移指南（Windows）](docs/新电脑环境搭建与项目迁移指南.md) 开始，包含基础软件安装、Git 拉取、虚拟环境、完整本地配置、数据迁移和 PyCharm 设置。

先按照 [后端说明](backend/README.md) 和 [前端说明](frontend/README.md) 配置依赖与环境变量；不要覆盖已经填写的 backend/.env。

项目根目录启动后端：

```powershell
.\venv\Scripts\python.exe -m uvicorn app.main:app --app-dir backend --reload
```

另一个终端启动前端：

```powershell
cd frontend
pnpm dev
```

聊天页面为 http://127.0.0.1:5173，接口文档为 http://127.0.0.1:8000/docs。请统一使用 127.0.0.1，不要混用 localhost 的登录 Cookie。

## 更新与边界

账号设置支持登录后直接修改登录用户名，修改密码仍需验证当前密码；聊天增加服务端额度、并发、超时、上下文预算、回答长度保护和脱敏日志。

详见 [聊天附件实现与验收](docs/聊天附件实现与验收.md)、[聊天历史实现与验收](docs/聊天历史实现与验收.md)、[账号设置与聊天质量优化](docs/账号设置与聊天质量优化.md) 和 [邮箱配置说明](docs/邮箱验证码与密码找回.md)。数据库启动时按迁移脚本升级到版本 9，升级前建议按说明备份。默认图片模型通过 QWEN_VISION_MODEL 配置；RAG 配置见 [RAG 检索与三模式使用说明](docs/RAG检索与三模式使用说明.md)。

用户自带 API 的入口是「账号设置 → 模型设置」，维护者需先安装更新后的后端依赖并配置 `MODEL_CONFIG_SECRET`；无需更改原有默认 Key。个人配置覆盖聊天、RAG 回答和 Coding 模型，Embedding 保持项目原配置。可选视觉模型也使用个人地址与 Key。配置方式、安全限制和验收步骤见 [用户自定义模型配置](docs/用户自定义模型配置.md)。

模型设置中提供「测试聊天」和「测试 Coding」：使用当前表单发起一次固定小请求，展示结果、耗时和错误原因，不自动保存配置，不读取聊天历史或执行文件工具。测试可能产生平台费用并计入项目调用额度；「重新检查配置」则只刷新加密存储状态，不调用模型。

聊天自动保存到当前账号，可切换、重命名、删除和分页查看；刷新、退出或修改密码不删除已保存的记录。调用统计与聊天正文分表保存。没有管理员后台、流式输出、邮箱更换或联网搜索，不支持扫描件 OCR。发送问题时，选取的上下文和附件内容会发送给当前选择的模型服务；RAG 的向量生成仍使用服务器配置的百炼服务，不是完全离线应用。

「编程工作台」支持一个对话绑定一个本地项目目录，首次连接后连续提出需求，无需每轮重新选择；后端保存多轮对话并提供近期上下文。停止仅结束本轮，主动断开或权限失效时需重新连接，退出账号清除该账号记住的目录绑定。界面保留中间对话、左侧目录、右侧过程和按需修改对照；旧 ZIP 入口已移除，历史数据保留。本模式需支持 File System Access 的桌面浏览器及 HTTPS/localhost，不执行本机命令、不需要 Docker，必要源码片段会发送给模型。详见 [本地文件编程与项目会话授权](docs/本地文件编程与一次授权.md)。

本轮按用户要求未执行功能测试，新增回归用例与手动验收步骤已提供。正式部署需额外配置 HTTPS、代理、可信客户端 IP 和备份恢复，不能把开发服务器直接当作生产部署。
